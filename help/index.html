Help

Practical guidance for using the Unit 3 Cyber Security Hub.

How to navigate the hub

Getting started . Show or hide navigation guidance
  • Use Home to enter the current week.
  • Open a week page (for example Week 1) to see that week’s full activity list.
  • Use Resources for material shared across several weeks.
  • On smaller screens, open the Menu button to reach the same navigation links.
  • Breadcrumbs near the top of internal pages show where you are and let you move back up a level.

If an activity does not submit

Recovery steps . Show or hide submission troubleshooting
  1. Check that all required fields are complete.
  2. Check that you have checked your answers where the activity asks you to.
  3. Allow pop-ups for the confirmation tab.
  4. Use Retry submission if the activity provides that button.
  5. Do not enter email addresses or passwords into formative activities.
  6. If submission still fails, note the activity name and contact your tutor.

Recommended browser guidance

Optional support . Show or hide browser guidance

Use a recent version of Chrome, Microsoft Edge or Firefox.

Allow pop-up windows for this site if an activity needs to open a confirmation tab after submission.

If a page does not load

Optional support . Show or hide page-load steps
  1. Refresh the page.
  2. Check your internet connection.
  3. Try opening the page again from the main navigation.
  4. Try a different recommended browser.
  5. If the problem continues, contact your tutor.

How confirmation tabs work

Optional support . Show or hide confirmation tab guidance

Some activities open a new browser tab after you submit results. That tab shows whether the staff collector accepted the submission. Keep the original activity tab open until you have checked the confirmation message.

Formative result collection

Optional support . Show or hide formative collection guidance

Selected activities can send results to a staff-controlled Google Sheet. This is for formative assessment and classroom feedback. It is not a secure examination system.

Write in your own words

Academic integrity . Show or hide academic integrity guidance

Learning responses and notes should be written in your own words. Do not paste flags, answer keys, walkthrough answers or copied solution text into the Unit 3 application.

Pasting is not blocked, but you will see a reminder on learning response fields. Learner details (name, student ID and class group) are excluded so you can enter them normally.

Tutors may review responses. If work appears to be copied from a walkthrough or answer key, your tutor may ask you to rewrite it or complete an alternative activity.

Privacy notice

Optional support . Show or hide privacy notice

Do not enter sensitive personal information such as email addresses, passwords, National Insurance numbers or full postal addresses into hub activities.

Use the class or group name provided by your tutor. Enter only the identity details the activity asks for.

Still having problems?

If access problems continue after trying the steps above, contact your tutor with the page address, the device and browser you are using, and a short description of what happened.
