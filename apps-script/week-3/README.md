# Week 3 Apps Script API

Standalone Week 3 collection and activity-content API for Unit 3 Cyber Security.

- Shares the Unit 3 spreadsheet used by Weeks 1 and 2
- Creates Week 3-specific tabs (`Week 3 Results`, `Week 3 Activity Catalogue`)
- Does **not** modify the Week 1 or Week 2 Apps Script projects

See `docs/week-3.md` for activity IDs, totals, deployment and verification steps.
