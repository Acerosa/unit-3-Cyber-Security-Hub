5. TryHackMe Practical: Vulnerabilities 101

In-class practical exploration of vulnerabilities, then a two-point reflection for Northbank.

Purpose

    Before opening the room

    Before starting, make sure you can explain the difference between a threat and a vulnerability.

    While completing the room

    Pay particular attention to:

      Open the TryHackMe room

      Opening the room does not mark this activity complete. Keep this Week 2 page open so you can return for notes and reflection.

      Completion requirements

      1. Complete the required TryHackMe tasks for Vulnerabilities 101.
      2. Return to this Week 2 application.
      3. Complete both reflection prompts below.
      4. Submit the existing two-point reflection activity.
      5. Check that the submission response confirms it was recorded.

      App states used here: Room opened · Reflection complete · Submission recorded · TryHackMe completion checked by tutor. Opening the TryHackMe link alone is not completion.

      Submit your result

      Submit after both reflections are complete. Detailed text stays in this browser; a summary is sent with your submission.
