Week 4: Motivations and Targets

LO2 — Understand the issues surrounding cyber security. OCR specification sections 2.3 Motivation for attackers and 2.4 Targets for cyber security threats.

Weekly learning outcomes

  • Identify and explain the range of motivations that drive cyber attackers.
  • Describe the four categories of target for cyber security threats: people, organisations, equipment and information.
  • Explain the methods that can be used during an attack on people, organisations, equipment and information.
  • Analyse how the motivation of an attacker influences the target selected and the method used.

Motivation = why · Target = what · Method = how

Examination focus

  • Read the question stem carefully so you answer for motivation when motivation is asked.
  • Do not use a method as an answer to a motivation question.
  • Recognise analyse as a command word that requires stated connections.
  • Use connective phrasing to make analytical connections visible.
  • Sustain one case throughout an extended response.
  • Manage time on higher-tariff questions so the final connection is written.
